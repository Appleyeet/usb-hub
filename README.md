# usb-hub (USBuddy)
I designed and created a USB hub following a guide from Hack Club! (https://macondo.hackclub.com/docs/usb-hub)
I built this USB hub since it seemed like a really cool project, and not too hard for a complete beginner. I also think that this device will come in handy
overall. I think it has an everyday use factor! I also added a keychain hole/slot into it so it can be carried around anywhere, even at school. It's also a discussion starter for sure!
This PCB USB hub has 2 USB-C and 2 USB-A ports, as well as a USB-C port for connecting to your laptop.
I do own a 3D printer and I have a laptop so I have some future plans for this. I want to create and design a case on OnShape to protect the components as well as make it more aesthetically pleasing. This case will have a thin slot in the same area as the slot on the PCB to still allow a keychain to be used. The PCB also contains 3 M2-sized screw holes that I can use to properly secure the board to my case.
